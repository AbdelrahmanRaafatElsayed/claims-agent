# claims-agent

An AI agent that answers questions about healthcare insurance claims by writing safe, read-only SQL. A learning and portfolio project, work in progress.

## Data notice: everything here is synthetic

All claims in this project are **synthetic**. They are generated by code (`src/claims_agent/generator.py`, seed 42). No real patient, provider, payer or employer data is used anywhere in this repository.

The generator's numbers (claim volumes, billed amounts, cancer-type mix) are my own assumptions, each tagged FACT, ESTIMATE or VERIFY in `src/claims_agent/generator_config.py`. No public claim-level billing data exists, so findings from this dataset describe the dataset, not the real Saudi market.

## What exists so far

- Validated `Claim` model (Pydantic) with custom errors and logging
- Seeded generator: 50,022 claims, 3,000 patients, 40 providers, Jan 2025 to Jun 2026, with one planted anomaly used as ground truth
- PostgreSQL schema with constraints (`sql/schema.sql`)
- 10 golden evaluation questions (`evals/golden_questions.json`) with reference SQL (`sql/golden_queries.sql`)
- 26 automated tests

Not built yet: the LLM agent, the API, and the safety layer that keeps the agent read-only.

## Known limitations

- All cancer types share one price curve, so differences between them are noise
- Denial odds do not depend on diagnosis or provider
- No patient age or treatment-type columns

## Run it

Requires Python 3.14 or newer, [uv](https://docs.astral.sh/uv/) and PostgreSQL with a database named `claims`.

```bash
uv sync
uv run python -m claims_agent.build_dataset   # writes data/claims.csv
psql claims -f sql/schema.sql
psql claims -c "\copy claims (claim_id, patient_id, provider_id, diagnosis_code, service_date, submission_date, billed_amount, status) FROM 'data/claims.csv' WITH (FORMAT csv, HEADER true)"
psql claims -f sql/golden_queries.sql
uv run pytest -v
```
